# Forecasting AAPL Volatility with GARCH and FinBERT News Sentiment

This project builds an end-to-end NLP and time-series pipeline to test whether lagged
financial-news sentiment improves one-day-ahead AAPL volatility forecasts beyond a
baseline GARCH(1,1) model.

## Project overview

The NLP stage filters **12,809 Apple-related headlines** from approximately **1.8
million financial-news records** and classifies each headline as positive, neutral,
or negative using the pretrained
[`yiyanghkust/finbert-tone`](https://huggingface.co/yiyanghkust/finbert-tone) model.
The labels are encoded as `1`, `0`, and `-1`.

The forecasting stage combines the sentiment features with adjusted AAPL closing
prices. To reduce look-ahead bias, each article is assigned to the next available
trading day. A baseline GARCH(1,1) model and a sentiment-augmented GARCH model are then
evaluated over the same 2018–2020 test period using expanding-window forecasts.

The augmented mean equation is

$$r_t = \mu + \gamma S_t + \epsilon_t,$$

while conditional variance follows

$$\sigma_t^2 = \omega + \alpha\epsilon_{t-1}^2 + \beta\sigma_{t-1}^2.$$

## Results

| Model | Variance MSE | QLIKE |
| --- | ---: | ---: |
| Baseline GARCH | 1.59523495e-06 | -7.051042 |
| GARCH + sentiment | 1.59382242e-06 | -7.051395 |

The sentiment model produced a slightly lower QLIKE loss, but the improvement was
negligible. In this experiment, a simple lagged daily-average sentiment feature did
not add meaningful predictive value beyond the volatility persistence already captured
by GARCH(1,1).

## Methods

- Download approximately 1.8 million financial headlines from Kaggle and filter
  Apple-related articles from the analysis period.
- Run batched FinBERT inference and checkpoint intermediate predictions to generate
  article-level sentiment scores.
- Download adjusted AAPL prices and calculate daily log returns.
- Split observations chronologically into training and test periods.
- Produce one-day-ahead forecasts using an expanding window.
- Align news to the next trading day and aggregate sentiment by target date.
- Compare models using variance MSE and QLIKE loss; lower values are better.

## Repository structure

```text
.
├── README.md
├── generate_sentiment_features.ipynb
├── garch_sentiment_analysis.ipynb
├── requirements.txt
└── data/
    ├── README.md
    └── tech_sentiment_progress.csv
```

`generate_sentiment_features.ipynb` creates the article-level sentiment CSV from the
raw Kaggle dataset. `garch_sentiment_analysis.ipynb` aligns those features with the
AAPL trading calendar and evaluates the forecasting models.

## Running the notebooks

1. Clone or download this repository.
2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start Jupyter from the repository root.

To reproduce the full pipeline, run the notebooks in this order:

1. `generate_sentiment_features.ipynb`
2. `garch_sentiment_analysis.ipynb`

FinBERT inference is computationally expensive, so a GPU runtime is recommended for
the first notebook. To reproduce only the forecasting experiment, skip the first
notebook and use the included `data/tech_sentiment_progress.csv` file.

The market prices are downloaded when the notebook runs. The sentiment CSV is read
from `data/tech_sentiment_progress.csv`; no Google Drive mount is required.

## Limitations

- Exact publication timestamps were unavailable, so news was conservatively aligned
  to the next trading day.
- Apple-related headlines were selected using keyword matching rather than entity-level
  company identification.
- Sentiment labels were generated by a pretrained FinBERT model without additional
  fine-tuning on this headline dataset.
- Daily averaging can obscure extreme sentiment and disagreement across articles.
- Squared daily returns are noisy proxies for latent daily variance.
- Results are limited to AAPL and the selected historical period.

## Data sources

- AAPL prices are downloaded using `yfinance`.
- Financial headlines come from Miguel Aenlle's Kaggle dataset,
  [Daily Financial News for 6000+ Stocks](https://www.kaggle.com/datasets/miguelaenlle/massive-stock-news-analysis-db-for-nlpbacktests),
  which is listed under the CC0: Public Domain license. The included CSV is the
  project-specific processed subset used in this analysis.
- Headline sentiment is generated with the pretrained
  [`yiyanghkust/finbert-tone`](https://huggingface.co/yiyanghkust/finbert-tone)
  financial-language model.
