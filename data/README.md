# Sentiment data

`tech_sentiment_progress.csv` is the project-specific processed subset used by the
notebook. The expected columns are:

- `date`: publication date
- `headline`: news headline
- `sentiment`: encoded sentiment score (`-1`, `0`, or `1`)

Source: Miguel Aenlle,
[Daily Financial News for 6000+ Stocks](https://www.kaggle.com/datasets/miguelaenlle/massive-stock-news-analysis-db-for-nlpbacktests)
on Kaggle. The dataset page lists the license as CC0: Public Domain.
